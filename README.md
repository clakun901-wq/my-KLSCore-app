# Kalsara Core - PWA OPFS Architecture

Aplikasi Micro-ERP Kalsara yang telah dimigrasi menggunakan arsitektur 100% Client-Side dengan SQLite Wasm/OPFS dan Web Workers.
Siap dihosting secara gratis di GitHub Pages tanpa backend server.

## Cara Hosting di GitHub Pages
1. Buat repository baru di GitHub (contoh: `kalsara-core`).
2. Ekstrak file ZIP ini dan *push* semua file beserta foldernya (`css`, `js`, `index.html`) ke repository tersebut.
3. Masuk ke tab **Settings** di repository GitHub Anda.
4. Pilih menu **Pages** di *sidebar* kiri.
5. Pada bagian **Source**, ubah *None* menjadi *branch* `main` atau `master`.
6. Klik **Save**.
7. Tunggu beberapa menit (refresh halaman), link GitHub Pages Anda akan muncul (contoh: `https://username.github.io/kalsara-core`).
